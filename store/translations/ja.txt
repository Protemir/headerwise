Headerwise は、Chrome と Edge で HTTP のリクエストヘッダーとレスポンスヘッダーを変更する拡張機能です。ヘッダーの設定・追加・削除をプロファイルにまとめ、必要な場所だけで有効にできます。

すべてブラウザの中で動きます。アカウントもアクセス解析もなく、拡張機能はどこにも何も送信できません。マニフェストでネットワーク接続を禁止しているため、ブラウザ自身がブロックします。ヘッダーの変更はブラウザが declarativeNetRequest で適用するので、Headerwise が閲覧中のページを読むことはありません。

できること
• リクエスト／レスポンスヘッダーの設定・追加・削除（プロファイルごと）。
• プロファイル：数に制限なし、複数を同時に有効化。複製、ドラッグで並べ替え（同じヘッダーを変更する場合は左側が優先）、キーボードショートカットで切り替え。
• フィルター：URL パターンや正規表現での「このページのみ」「このページでは無効」、特定サイトからのリクエストのみ、特定の種類（ページ、fetch/XHR、スクリプトなど）やメソッドのみ、または 1 つのタブのみ。
• リダイレクト：アドレスの一部を置き換えます。たとえば api.example.com へのリクエストをステージングサーバーへ送れます。
• このタブ：ポップアップを開くと、現在のページでどのプロファイルが何件のリクエストを変更したか、別のプロファイルが適用されなかった理由がわかります。
• DevTools から貼り付け：リクエストを cURL・fetch・PowerShell としてコピーして貼り付け、必要なヘッダーを選ぶだけ。
• プリセット：CORS、Content-Security-Policy の削除、iframe での表示許可、Bearer トークン、キャッシュ無効、iPhone や Googlebot の User-Agent など。
• 変数：{{uuid}}、{{timestamp}}、{{date}} など。編集のたびに値が入り、1 分ごとに更新されます。
• 秘密情報は非表示：トークンや Cookie は目のアイコンを押すまで「•」で表示され、画面共有でも安心です。
• 一定時間だけオン：プロファイルを 15 分から 8 時間だけ有効にすると、時間が来たら自動でオフになります。トークンや本番用ヘッダーの消し忘れを防げます。
• プロファイルを JSON でエクスポート／インポート。秘密の値は指定しない限り含まれません。Requestly と Simple Modify Headers のエクスポートもインポートできます。
• 自動テスト：Selenium、Playwright、Puppeteer 向けの専用ビルドで、テストからヘッダーを設定できます。ModHeader 用に書いたテストも拡張機能を差し替えるだけで動きます。ダウンロードと設定方法：https://protemir.github.io/headerwise/automation.html
• ライトテーマとダークテーマ。

MODHEADER から移行する方へ
ModHeader は 2026 年 7 月に Chrome と Edge のストアから削除されました。ブラウザで無効化されるとエクスポートボタンも使えなくなりますが、プロファイルはディスクに残っています。Headerwise はページ上で ModHeader のフォルダーを直接読み込み（アップロードは一切なし）、フィルター、リダイレクト、Cookie ルールごとプロファイルを移行します。ModHeader からエクスポートした JSON ファイルも使えます。

DEVTOOLS だけではだめなの？
DevTools はヘッダーを確認するには最適です。ただし、すべてのリクエストに Authorization などのリクエストヘッダーを追加することはできず、オーバーライドはそのタブで DevTools を開いている間しか効きません。Headerwise は一時停止するまで、すべてのタブで常に動作します。

無料・制限なし。ここに挙げた機能はすべて無料で、今後も無料のままです。
