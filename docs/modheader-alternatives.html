ModHeader alternatives in 2026: what to switch to

ModHeader was removed from the Chrome Web Store and Edge Add-ons in July 2026, after a dormant collector for visited domains was found in version 7.0.18. If you used it every day, here is what to look for in a replacement, and the extensions people are moving to.

Before you switch, save your profiles. If Chrome turned ModHeader off, its Export button is gone, but the profiles are still on your disk until you click "Remove". Where they are and how to get them out.

Disclosure: I make Headerwise, one of the extensions below. I've tried to describe the others only by what their own pages and store listings say; corrections are welcome on GitHub.

What to check in any header extension

A header editor sees, or can change, every request your browser makes, often with your tokens in it. That's exactly why ModHeader's removal hurt. A few things are worth a look before you install the next one:

  • Can it send data anywhere? An extension's manifest can forbid network requests for its own pages (connect-src 'none' in content_security_policy). Then the browser blocks any request it tries to make, whatever the code says. It's worth checking whether yours does.
  • Does it read your pages? Extensions built on Chrome's declarativeNetRequest hand the header rules to the browser and never see page content or request bodies. Older designs read every request.
  • Is the code open, and does the store build match it? Open source helps only if you or someone else can compare the build with the source.
  • What does the free version leave out? ModHeader limited its free tier; check what your replacement keeps for paying users.
  • Does it read your old ModHeader profiles? Re-typing a dozen profiles with filters is the part nobody enjoys.
  • Response headers, filters, tests. If you change CORS or CSP response headers, limit headers to some sites, or set headers in Selenium or Playwright, make sure the replacement does those too.

The options

Requestly

The largest of the alternatives, and more than a header editor: redirects, mock responses, an API client and team workspaces. Its pages say header rules are free, and it has its own page for moving from ModHeader. Team features are paid. A good fit if you want one tool for headers, mocks and API testing; more than you need if you only switch a few headers. requestly.com

Modify Header Value

A small, long-standing extension for adding, changing or removing request headers per site, with an on/off switch in the toolbar. Its store description covers request headers only. Chrome Web Store

Simple Modify Headers

A simple request and response header editor, popular in Firefox. It hasn't been updated since mid-2024. Firefox Add-ons

Modify Header (SelectorsHub)

An open source header editor from the makers of SelectorsHub, presented as a privacy-first replacement for ModHeader. selectorshub.com

Headerwise

The one I wrote, free and MIT licensed. Built for the checks above:

  • its manifest sets connect-src 'none', so it can't send anything anywhere, and the rules are applied by Chrome through declarativeNetRequest;
  • reads ModHeader's folder from your disk in the page itself, even after Chrome turned ModHeader off, and imports ModHeader, Requestly and Simple Modify Headers exports;
  • request and response headers, redirects, "only on" / "never on" filters, sites, request types and methods, one tab only, a timer that switches a profile off;
  • "On this tab" shows which profile changed how many requests, which DevTools may not show;
  • share a profile by link, and sync between your computers through the browser's own account, without a server of its own;
  • an automation build for Selenium, Playwright and Puppeteer that keeps ModHeader's test URLs working.

Chrome and Edge (from the Chrome Web Store); no Firefox version yet. Chrome Web Store · source · more

Which one to pick

  • You switched a few request headers by hand: any of them will do. Pick by what you trust.
  • You had many profiles, filters and response headers in ModHeader: one that imports them and handles response headers (Requestly, Headerwise).
  • You also want mocks, an API client and a team workspace: Requestly.
  • You care most that the extension can't phone home: look for connect-src 'none' in its manifest, or read its code.
  • Firefox: Simple Modify Headers or Modify Header Value.
