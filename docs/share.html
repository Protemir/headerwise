Install Headerwise

Headerwise isn't installed in this browser. It's free, from the Chrome Web Store (Chrome, Edge, Brave); once it's in, open this link again.

Already have it, or using another browser? Copy this link and paste it into Headerwise: Import JSON, then Import.

The profiles come in switched off, so you can look them over first. Secret values such as tokens and cookies are never in a share link: fill in your own.
